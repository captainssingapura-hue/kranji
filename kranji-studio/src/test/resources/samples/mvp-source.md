# 雨 {#yu}

下雨的时候，天是灰的，路是亮的。这一篇说的就是雨。

## 一、雨是从哪里来的 {#cong-na-li-lai}

太阳把海里的水晒热，水就变轻，一直往上飞。飞到很高很高的地{dì}方，
天冷了，水又聚在一起，变成云。

云里的水越聚越多，重得飘不动了，就落下来。落下来的那一段路，我们
叫它雨。

## 二、雨的样子 {#yang-zi}

小的时候，雨是一根一根的线，落在水里画出一个一个的圆。

大的时候，雨是一片一片的，打在窗上，声音像有人在外面撒豆子。

### 二之一、雨前和雨后 {#qian-hou}

下雨之前，风先来，树叶都翻过来给你看它们的背面。

下雨之后，屋顶在滴水，空气是甜的——那是泥土被泡开的味道。

## 三、古人怎么写雨 {#gu-ren}

一千多年前的人，也在看同一场雨。

```verse
好雨知时节，
当春乃发生。

随风潜入夜，
润物细无声。
```

写这四句的人叫杜甫。他说好的雨懂得挑时候，趁着晚上悄悄地下，把东西
都润湿了，却一点声音也没有。

## 四、自己看一看 {#kan-yi-kan}

下次下雨，你可以站在窗边看一看：雨是斜的还是直的？它先落在哪里？

看完了，也可以像杜甫那样，用四句话把它写下来。
